# דף נחיתה — צחי בוזגלו, ייעוץ השקעות

דף נחיתה שיווקי בעברית, RTL מלא, מוכן להעלאה ל-Lovable.

## קבצים

| קובץ | מה זה |
|---|---|
| `tzahi-buzaglo.html` | תצוגה מקדימה עצמאית — נפתח בכל דפדפן, בלי התקנות |
| `TzahiLanding.tsx` | קומפוננטת React + Tailwind + shadcn/ui — הקובץ שנדחף ל-Lovable |

שני הקבצים זהים ויזואלית.

## עיצוב

- **פונטים:** Rubik (כותרות) + Assistant (גוף) — סאנס-סריף מודרני, ללא תגים
- **פלטה:** רקע כהה `#07090E`, זהב `#EFBF4A`, טקסט שמנת `#EDEAE3`
- **RTL מלא:** תכונות לוגיות (`inset-inline`, `padding-inline`, `start/end`), חצים לכיוון שמאל, מספרים ואימייל ב-`dir="ltr"`
- מרקם גרעין, קווי רשת, פס התקדמות גלילה, אנימציית מונים, גרף SVG שמצייר את עצמו

## טופס הלידים

ב-`TzahiLanding.tsx` הטופס שולח POST ל-`LEAD_ENDPOINT` (ברירת מחדל: `/functions/v1/send-lead`).
צריך להקים Supabase Edge Function עם Resend שתשלח את הליד למייל של צחי.
